# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer built using **Java, Spring Boot Microservices, Angular, PostgreSQL, Redis, Kafka, Docker, and AWS**.

The platform helps job seekers optimize their resumes by analyzing them against job descriptions, generating ATS scores, identifying skill gaps, and providing AI-powered improvement suggestions.

---

# 📌 Features

## MVP

- User Authentication (JWT)
- Resume Upload (PDF/DOCX)
- Job Description Upload
- ATS Score Calculation
- Resume vs JD Matching
- Skill Gap Analysis
- AI Suggestions
- Analysis History
- PDF Report Download
